## App Description
Pantry Chef is a Node.js/Express web app that lets users search for recipes by ingredient using the TheMealDB API. Users can save recipes to a MongoDB database, view the full ingredient list and instructions, add personal notes to saved recipes, and get a random recipe suggestion.
